# 双历生日提醒（Android）

输入姓名与公历出生日期，应用会自动换算对应的中国农历生日，并在以后每年的公历生日和农历生日当天 00:00 发送高优先级提醒。

## 当前功能

- 保存多人生日，支持修改姓名和出生日期、单独暂停及删除。
- 日期选择器会在日历上方实时显示当前所选日期对应的农历日期。
- 基于 Android ICU 中国农历历法换算，支持闰月。
- 分别展示下一次公历生日和农历生日对应的公历日期。
- 使用一次性精确闹钟，触发后自动续排下一年。
- 设备重启、系统时间/时区变化、应用升级后自动恢复提醒。
- Android 13+ 通知权限与 Android 12+ “闹钟和提醒”特殊权限引导。
- 公历与农历生日同一天时合并成一条通知。
- 每天检查 GitHub Releases；默认仅在 Wi-Fi 下自动下载新版，完成 SHA-256 校验后提醒安装。

## 日期规则

- 2 月 29 日在非闰年按 2 月 28 日提醒。
- 农历三十遇到只有廿九的小月时，按廿九提醒。
- 闰月生日优先在同一闰月提醒；某年没有该闰月时，按同月普通月份提醒。
- 农历换算按中国历法固定的 GMT+8 天文规则；提醒时间按设备当前时区的当地 00:00。

## 构建

1. 用 Android Studio 打开本目录。
2. 等待 Gradle 同步完成。
3. 运行 `./gradlew assembleDebug`，APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

正式 APK 在仓库的 Releases 页面下载。Android 会要求用户确认安装；普通应用无法静默覆盖升级。

最低支持 Android 7.0（API 24），目标版本 Android 14（API 34）。

当前版本：1.2.1。

## 发布新版本

1. 修改 `app/build.gradle.kts` 中的 `versionCode` 和 `versionName`。
2. 合并代码并创建与版本号一致的标签，例如 `v1.2.0`。
3. 推送标签后，GitHub Actions 会测试、使用仓库 Secrets 中的发布密钥签名，并自动创建带 APK 的 Release。

发布签名密钥不会提交到仓库。必须永久安全备份同一份密钥；Android 只允许使用相同签名覆盖安装后续版本。

## 系统限制

现代 Android 不允许普通应用在后台任意弹出 Activity。本项目采用系统允许的高重要性悬浮通知（heads-up notification）；通知能否悬浮、声音和振动最终受用户的系统通知渠道设置与厂商省电策略控制。首次添加生日后，请在首页完成通知和精确提醒授权。
